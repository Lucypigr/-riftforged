# PORTABILITY

## Web
Static deployment compatible with GitHub Pages.

## Mobile
Prototype uses Pointer Events, touch-action suppression and viewport safe-area CSS. Future packaging options: PWA or Capacitor.

## Unity migration
Not one-click. Preserve data schemas and acceptance tests, then reimplement rendering/input/physics in Unity C#. Loot, affix, skill and enemy configuration can be translated mechanically from the data layer.
